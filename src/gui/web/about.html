About Spotify Power Tools
A smart Spotify desktop companion for better shuffle, playlist insights, duplicate detection, safe playlist cleaning, tray controls, global hotkeys, and quiet background listening.

What This App Does

Spotify Power Tools helps you improve how you listen to playlists.

It generates smarter shuffle previews, adds smart-shuffled songs directly to your Spotify queue, analyzes playlist health, finds duplicate tracks, and creates cleaned playlist copies without modifying the original playlist.

Gaming Mode

silent companion

Gaming Mode lets Spotify Power Tools stay useful while you are in a game, without pulling focus away from what you are doing.

No focus stealing
Preview and queue hotkeys run quietly instead of bringing the app to the front.
Quiet feedback
Errors and confirmations use tray/status messages instead of intrusive popups.
Lower background load
Refresh timers slow down while Gaming Mode is active to reduce API pressure.

Safety Design

Spotify Power Tools is designed to be safe by default.

The app does not overwrite your original playlists. Cleaner features create new playlist copies instead of deleting or modifying your existing playlists.
