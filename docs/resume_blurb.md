# Spotify Power Tools — Resume Blurb

## Short version

Built a Python/PySide6 desktop application for Spotify that adds intelligent playlist shuffling, explainable queue previews, playlist analytics, local listening-memory insights, duplicate detection, global hotkeys, system tray controls, and a quiet Gaming Mode.

## Resume bullets

- Built a Spotify desktop companion app in Python with PySide6, Qt WebEngine, Spotipy, and the Spotify Web API.
- Implemented smart playlist shuffling with configurable profiles, queue-size control, local ratings, recent-track memory, replay/skip signals, and explainable preview output.
- Designed a premium WebEngine-based GUI with custom typography, dark editorial styling, playlist analytics, queue/search pages, and dashboard cards.
- Added system tray integration, configurable global hotkeys, Gaming Mode, local JSON persistence, safe playlist-cleaning flows, and Git/GitHub project hygiene.

## Interview explanation

Spotify Power Tools started from a real user-experience problem: Spotify shuffle can feel repetitive in large playlists. I built a desktop companion app that reads the currently playing Spotify playlist, analyzes the tracks, generates a smarter queue order, and lets the user preview and queue that order directly into Spotify.

The project includes API integration, local state management, background workers, desktop UI design, global hotkeys, tray behavior, and safe data handling. I also built playlist analytics and listening-memory features so the app can adapt based on ratings, replays, skips, and recent listening behavior.
