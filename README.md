# Spotify Power Tools

Spotify Power Tools is a desktop companion application for Spotify that provides intelligent playlist shuffling, playlist analytics, and explainable music recommendations.

---

## Features

- Smart Shuffle
- Explainable Shuffle
- Playlist Analytics
- Beautiful Desktop Interface
- Spotify Integration
